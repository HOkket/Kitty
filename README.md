# Kitty Backup

Meu backup do terminal kitty.

## Instalação

Para clonar este repositório e movê-lo para a pasta de configuração do kitty, execute o seguinte comando:

```bash
git clone https://github.com/HOkket/Kitty_backup.git && mv Kitty_backup ~/.config/kitty
```

### Passo a passo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/HOkket/Kitty_backup.git
   ```

2. **Mova para o diretório de configuração do kitty:**
   ```bash
   mv Kitty_backup ~/.config/kitty
   ```

Ou combine os dois comandos em um único comando, como mostrado acima.

## Sobre

Este projeto contém os arquivos de configuração do terminal kitty para backup e fácil restauração em novas instalações.

---

**Nota:** Se já existir uma pasta `~/.config/kitty`, você pode fazer backup da versão anterior antes de executar o comando de instalação.
